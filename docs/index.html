Core SSOT

Roof Ledger Dashboard

Live monthly totals computed directly from SQLite. Instantly view collected rent vs. expected rent, unpaid balances, overdue tenants, and vacant units in Light or Dark mode.

Partial Payments & Tenant SOA

Accept partial or advance payments with automatic running balance calculation. Generate complete Tenant Statements of Account (SOA), sequential receipts, and void/adjustment audit trails.

Security Deposit Escrow & Move-Out

Security deposits are tracked strictly as escrow liabilities (never inflated into rent income). Record itemized repair/cleaning deductions at move-out and compute exact refunds.

How to Install on Android

Follow these quick steps to install the official APK directly on your Android phone or tablet.

1

Download the Official APK

Tap the Download Tenera APK button above to download app-release.apk from GitHub Releases to your Android device.

2

Allow Installation from Browser

If your phone displays "For your security, your phone is not allowed to install unknown apps from this source", tap Settings and toggle Allow from this source ON.

3

Install & Start Your 14-Day Free Trial

Tap Install and then Open. Tenera launches immediately with zero sign-up required and your 14-day full-feature trial active offline!

4

Seamless In-App Updates

Whenever a new version is published on GitHub Releases, Tenera automatically notifies you inside the app (or check anytime via More ➔ Check for Updates).
