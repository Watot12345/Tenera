✓ LATEST STABLE RELEASE

Version v1.0.1 (Audit, SOA, Operations & Security Update)

Target: Android 7.0+ (API 24 to 35) · Offline SQLite SSOT

🧾 Ledger, Partial Payments & Security Deposit Escrow

  • Partial & Advance Payments (BR-6 / FR-E3): Record partial rent payments or advance credits with automatic running balance calculation.
  • Tenant Statement of Account (SOA / FR-E4): Full chronological ledger per tenant showing rent charges, utility splits, payments, and running balance.
  • Void & Adjustment Audit Trail (BR-2 / FR-E6): Mistaken payment entries can be voided with a mandatory reason while preserving immutable financial history.
  • Move-Out Deposit Settlement & Escrow Reports (BR-4 / FR-D7 / FR-H7): Security deposits are tracked strictly as escrow liabilities (never inflated into collected rent income), with move-out deduction itemization and refund calculation.

🏢 Tenant ID, Late Fees, Maintenance & Operations

  • Government ID Attachment (FR-C2) & Late-Fee Rules (FR-D5): Attach tenant ID photos offline and configure optional per-lease grace days and late penalties with 1-tap landlord waiver support.
  • Expense Tracker & Maintenance Tickets: Log operating expenses per property and track unit repair/maintenance tickets from reported to resolved.
  • Arrears Aging Report (FR-H3) & SQLite Health Check (FR-I4): Bucket overdue balances by 1–30, 31–60, 61–90, and 90+ days, and run on-demand SQLite PRAGMA integrity_check diagnostics.
  • Sub-Meter Utility Splitter & Printable Lease Contracts: Compute exact electric/water sub-meter shares and generate printable Philippine lease contracts.

🛡️ Security, Play Protect & Experience

  • Play Protect Verified Safe: Removed direct SEND_SMS permission in favor of launching the device's default SMS app with pre-filled reminders — eliminating Android Play Protect warnings.
  • 14-Day Anti-Bypass Trial & Tier Gating: Full 14-day trial on install, Starter (₱49/mo, 1 property up to 15 units, AdMob supported), and 100% Ad-Free Tenera Pro & Business tiers.
  • Refined Light & Dark Mode: High-contrast Roof Ledger palette with streamlined action buttons and zero redundant dialog clutter.

PREVIOUS RELEASE

Version v1.0 (Initial Public Release)

Release Date: October 2026 · Target: Android 7.0+ (API 24 to 34+)

🚀 Architecture & Features

  • SQLite SSOT: Removed all static lists. All properties, rooms, tenants, and payment logs query and write to local SQLite.
  • Dynamic Ledger Math: Live calculation of collected amount, expected amount, vacant units, and overdue counts.
  • In-App Updates: Automated update checker using GitHub Releases API with changelog prompt and direct APK download.
  • Firebase Cloud Sync: Optional SQLite-to-Firestore hybrid sync engine with device-partitioned landlord storage.
  • Payment Logging: Live tenant candidate search, optional cash photo proof, and digital reference numbers for GCash / Bank Transfer.
  • Room Matrix: Color-coded visual room status grid with tenant long-press vacate action.
